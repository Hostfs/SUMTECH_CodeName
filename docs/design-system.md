# 디자인 시스템: 내 옷장

값의 원본은 `design/html/*.html` 안의 `<style>`이다. 이 문서는 그 값을 정리한 것이다.

## 1. 색상

### 공통(고정)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F7F6F3` | 기본 배경(아이보리) |
| `--card` | `#FFFFFF` | 카드, 입력, 탭 바 |
| `--ink` | `#1D1D1F` | 주요 글자 |
| `--sub` | `#666666` | 보조 글자 |
| `--line` | `#E6E4E0` | 테두리, 구분선 |
| `--tile` | `#F9F8F5` | 카드 안 사진 영역 배경 |
| (없음) | `#9A9892` | 비활성 값('미입력', 플레이스홀더) |
| (없음) | `#EEEDEA` | '위치 미지정' 회색 배지 배경 |

### 계절 테마

포인트(primary)는 지정값이고, 나머지는 제안값(파생)이다.

| 토큰 | 봄 | 여름 | 가을 | 겨울 | 용도 |
|---|---|---|---|---|---|
| `--primary` | `#F7B1B0` | `#2EC4B6` | `#A47148` | `#134074` | 주요 버튼, 선택된 칩·탭, 체크, 선택 카드 테두리, 로고 배경 |
| `--on` | `#1D1D1F` | `#1D1D1F` | `#FFFFFF` | `#FFFFFF` | primary 위 글자·아이콘 |
| `--soft` | `#FDEFEF` | `#E3F7F5` | `#F3E9E1` | `#E4EBF4` | 보조 배경(위치 카드, 배지, 안내 칸, 선택 카드 사진 배경) |
| `--deep` | `#8A4A49` | `#17766D` | `#7F5532` | `#134074` | 작은 강조 글자, 링크, 활성 탭 글자, 배지 글자 |

대비 메모:
- 봄과 여름은 밝은 색이라 primary 위 글자를 어둡게 쓴다.
- 가을 primary 위 흰 글자는 약 4.2:1이므로 굵게 15px 이상만 쓴다.
- 작은 강조 글자는 항상 `--deep`을 쓴다.

구현 예시:

```css
:root, [data-season="autumn"] { --primary:#A47148; --on:#FFFFFF; --soft:#F3E9E1; --deep:#7F5532; }
[data-season="spring"] { --primary:#F7B1B0; --on:#1D1D1F; --soft:#FDEFEF; --deep:#8A4A49; }
[data-season="summer"] { --primary:#2EC4B6; --on:#1D1D1F; --soft:#E3F7F5; --deep:#17766D; }
[data-season="winter"] { --primary:#134074; --on:#FFFFFF; --soft:#E4EBF4; --deep:#134074; }
```

`<html data-season="...">`에 적용한다. 설정은 `auto | spring | summer | autumn | winter`이고, auto는 Asia/Seoul 기준 월로 계산한다.
첫 렌더 깜빡임을 막기 위해 서버나 인라인 스크립트에서 미리 정한다.

### 날씨 배경 (홈 전용)

| 상태 | 처리 |
|---|---|
| 맑음 | 위→아래 그라데이션 `#CFE6F7` 0% → `#E4F0F8` 28% → `#F7F6F3` 50% 이후 고정. 오른쪽 위에 연한 햇빛 원(`#FFF7DC`, 방사형으로 투명해짐), 흰 구름 2개(불투명도 0.8~0.9) |
| 흐림 | 그라데이션 `#C7CBD0` 0% → `#DCDDDD` 30% → `#F7F6F3` 52% 이후 고정. 회색 구름 3개(`#A5ACB4`~`#C3C7CC`, 불투명도 0.65~0.7), 배경 레이어 전체에 `filter: blur(8px)` |
| 이후 추가 | 비, 눈, 밤 (같은 원칙: 화면 위쪽 절반에만, 아래는 `--bg`로 이어짐) |

배경은 화면 위쪽 절반에만 깐다. 카드, 검색창, 위젯은 항상 흰색 불투명 카드로 둔다(유리 효과 금지). 다른 화면과 분위기를 맞추기 위해서다.

## 2. 글꼴

- `font-family: "Pretendard", "Noto Sans KR", system-ui, sans-serif;` (목업은 Noto Sans CJK로 렌더링되었다)
- `letter-spacing: -0.01em` 기본. 제목은 -0.02 ~ -0.025em
- 전역 `word-break: keep-all;`, `-webkit-font-smoothing: antialiased;`

| 역할 | 크기/굵기 | 예 |
|---|---|---|
| 페이지 제목 | 24px / 600 | 내 옷장, 보관함, 마이 |
| 홈 인사말 | 26px / 600, 줄간격 1.3 | 안녕하세요, 하늘님 |
| 상세 옷 이름 | 22px / 600 | 베이지 블레이저 |
| 위치 강조 값 | 20px / 700 | 옷장 A › 왼쪽 행거 |
| 상단바 제목 | 17px / 600 | 옷 정보, 옷 등록 |
| 섹션 제목 | 16~17px / 600 | 최근 등록한 옷, 세탁·관리 정보 |
| 카드 이름 | 15px / 600 | |
| 본문·입력 | 15~16px / 400 | |
| 보조 | 13~14px / 400, `--sub` | |
| 캡션 | 12~12.5px | 위치 한 줄, 탭 라벨(11.5px) |
| 큰 숫자 | 46px / 600 (날씨 기온), 20~22px / 700 (통계) | |

## 3. 간격·모양

- 8px 단위: 4·8·12·16·20·24·32
- 화면 좌우 여백 16px(카드 열), 20px(텍스트 행)
- 카드: `border:1px solid var(--line); border-radius:16px` (큰 카드 18px), 안쪽 여백 8~16px
- 카드 사이 간격 12px, 리스트 행 간격 8px
- 버튼: 높이 44px(일반) / 50px(하단 고정) / 36px(작은), `border-radius:999px`, 글자 15~16px/600
- 칩: 높이 36px, 좌우 13px, 999px, 기본은 흰 바탕 + `--line` 테두리, 선택은 `--primary` 바탕 + `--on` 글자 600
- 검색창: 높이 44px(목록), 56px(홈), 999px, 흰 바탕, 돋보기 아이콘 `--sub`
- 그림자: 사용하지 않는다(폰 프레임 합성용 외에는 없음)
- 터치 영역 최소 44×44

## 4. 컴포넌트

- **상태바/상단바**: 상단바 높이 48px, 좌 뒤로가기(44px 터치), 가운데 제목 17px/600, 우 더보기(⋯)
- **하단 탭 바**: 높이 84px, 흰 바탕, 위쪽 `--line` 1px.
  - 탭 5칸(홈, 내 옷장, +, 보관함, 마이). 아이콘 24px, 라벨 11.5px.
  - 활성 탭은 `--deep` 글자와 600 굵기.
  - 가운데 + 버튼: 52px 원, `--primary` 바탕, 흰 4px 링(`box-shadow:0 0 0 4px #fff`)
- **옷 카드(목록)**: 흰 카드 16px, 안쪽 8px.
  - 사진 영역 높이 128px, `--tile` 바탕, 모서리 12px.
  - 이름 15px/600 한 줄 말줄임.
  - 위치 한 줄: 핀 아이콘 13px + 12.5px `--sub`. 위치가 없으면 '위치 미지정' 회색 배지.
- **선택 모드**: 카드 왼쪽 위에 26px 원형 체크.
  - 선택하면 원이 `--primary`가 되고, 카드 테두리가 2px `--primary`, 사진 배경이 `--soft`가 된다.
  - 하단에 떠 있는 액션 바(높이 60px, 18px 모서리, 흰 카드)에 `n개 선택됨 · 선택 해제 · [위치 변경]`
- **위치 카드(상세)**: `--soft` 바탕, 18px 모서리. 왼쪽에 44px `--primary` 원 + 핀 아이콘, 라벨 '보관 위치' 13px, 값 20px/700
- **정보 표(상세)**: 흰 카드, 2열. 각 칸은 라벨 13px `--sub`(폭 44px, 줄바꿈 금지) + 값. 행 사이 구분선. 빈 값은 '미입력' `#9A9892`
- **빈 안내 박스**: 점선 테두리 `#D5D2CB`, 반투명 흰 바탕, 안내 글 13px + 테두리 버튼(`--primary` 테두리, `--deep` 글자)
- **배지**: 높이 26px, `--soft` 바탕, `--deep` 글자 13px/600
- **세그먼트 탭(코디)**: 높이 42px, 바탕 `#ECEAE5`. 선택 칸은 `--primary` 바탕 + `--on` 글자
- **날씨 위젯(홈)**: 흰 카드 18px, 안쪽 16px. 구성은 아래 순서다.
  - 지역·날짜
  - 기온(46px/600)과 날씨명·최고최저, 큰 아이콘(40px, `--deep`)
  - 구분선
  - 5칸 시간대 예보
  - 안내 칸(`--soft` 바탕, 14px 모서리): 36px 흰 원 아이콘 + 두 줄 문구 13.5px/1.5 + '코디 보기 ›'

## 5. 문구 규칙

- 해요체, 짧게. 버튼은 동사형('위치 변경', '저장', '코디 저장')
- 안내 문구는 문장 단위로 `<br />` 줄바꿈을 직접 넣는다. 각 줄이 한 줄 안에 들어가야 한다.
- 성공 안내 예: "n개의 옷을 '옷장 A'로 옮겼어요", "코디를 저장했어요", "등록했어요"
- 확인 창 예: "정말 삭제할까요? 코디에서도 빠져요."

## 6. 하지 말 것

- 네 계절 색을 한 화면에 장식으로 함께 쓰기. 단, 테마 선택 화면의 색 미리보기 점은 예외다.
- 그림자, 장식용 그라데이션(홈 날씨 배경 제외), 유리 효과 카드
- 명조체 등 두 번째 글꼴
- 파란 링크색이나 검은 내비게이션(참고 디자인 MD의 요소는 쓰지 않는다)
