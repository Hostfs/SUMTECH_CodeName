# 화면 명세: 내 옷장

각 화면에는 목업 파일 경로와 원본 HTML 경로를 함께 적었다. 문구는 목업과 같게 쓴다. `/`는 줄바꿈 위치를 뜻한다.
**목업 없음** 표시는 디자인이 아직 없는 화면이다. 같은 디자인 시스템으로 구현하고, 구현한 뒤 스크린샷을 남긴다.

---

## 1. 홈 `/`

- 목업: `design/mockups/iphone/0{1-4}_home_{season}_iphone.png` (왼쪽 맑음, 오른쪽 흐림)
- HTML: `design/html/home_{season}_{sunny|cloudy}.html`

위에서 아래 순서:
1. 날씨 배경(화면 위쪽 절반, `design-system.md` 1절 참고). 상태바는 배경 위에 보이게 둔다.
2. 헤더: 왼쪽은 로고(32px, `--primary` 둥근 사각형 + 옷걸이 아이콘)와 '내 옷장'. 오른쪽은 알림 버튼(40px 흰 원).
3. 가운데 정렬 인사 영역:
   - 날씨 알약: 아이콘 + `오늘은 {맑음|흐림} · {기온}`
   - 인사말: `안녕하세요, {이름}님`
   - 날씨별 두 줄 문구(아래 표)
4. 검색창(56px): 왼쪽 `+`(옷 등록), 플레이스홀더 `이름·색상·위치로 검색`, 오른쪽 `--primary` 원형 검색 버튼
5. 바로가기 칩 3개: `위치 정하기` · `코디 만들기` · `옷 등록`
6. 날씨 위젯(하단 탭 위):
   - 지역과 날짜, 기온, 날씨명, `최고 n° · 최저 n°`
   - 시간대 5칸(`지금`, 15시, 18시, 21시, 24시)
   - 안내 칸(아래 표 문구) + `코디 보기 ›`
7. 하단 탭(홈 활성)

날씨별 문구:

| 계절 | 날씨 | 인사 아래 문구 | 위젯 안내 문구 |
|---|---|---|---|
| 봄 | 맑음 | 따뜻한 봄날이에요. / 오늘은 어떤 옷을 찾아볼까요? | 아침저녁은 쌀쌀해요. / 가벼운 카디건을 챙겨 보세요. |
| 봄 | 흐림 | 구름이 많은 봄날이에요. / 얇은 겉옷부터 찾아볼까요? | 오후에 비가 올 수 있어요. / 우산을 꼭 챙겨 주세요. |
| 여름 | 맑음 | 햇살이 강한 여름날이에요. / 시원한 옷부터 찾아볼까요? | 한낮에 많이 더워요. / 통기성 좋은 옷을 골라 보세요. |
| 여름 | 흐림 | 흐리고 습한 날이에요. / 가벼운 옷부터 찾아볼까요? | 소나기가 올 수 있어요. / 가벼운 옷을 골라 보세요. |
| 가을 | 맑음 | 맑은 가을날이에요. / 오늘은 어떤 옷을 찾아볼까요? | 일교차가 커요. / 얇은 아우터를 챙겨 보세요. |
| 가을 | 흐림 | 하늘이 흐린 날이에요. / 포근한 옷부터 찾아볼까요? | 저녁에 비가 올 수 있어요. / 가벼운 아우터를 챙겨 보세요. |
| 겨울 | 맑음 | 맑지만 추운 겨울날이에요. / 따뜻한 옷부터 찾아볼까요? | 바람이 차가워요. / 두꺼운 아우터를 챙겨 보세요. |
| 겨울 | 흐림 | 하늘이 흐린 겨울날이에요. / 포근한 니트부터 찾아볼까요? | 밤에 눈이 올 수 있어요. / 미끄럼에 주의하세요. |

구현 메모:
- 날씨 데이터는 `WeatherProvider` 인터페이스 뒤에 둔다. 1차는 목업 데이터를 쓰고, 날씨 상태 `sunny | cloudy`(이후 `rain | snow | night`)로 배경과 문구를 고른다.
- 문구는 (계절 × 날씨) 표로 관리한다.
- 날씨를 가져오지 못하면 위젯 대신 `날씨 정보를 불러오지 못했어요.` / `잠시 후 다시 시도해 주세요.`를 보여 주고, 배경은 `--bg` 단색으로 둔다. (목업 없음)

## 2. 내 옷장 `/closet`

- 목업: `design/mockups/screens/0{1,3,5,7}_{season}_closet.png`, HTML `design/html/closet_{season}.html`. 목업은 **선택 모드** 상태다.
- 상단: 제목 `내 옷장` + 보조 `총 42벌`, 오른쪽 `선택`(선택 모드에서는 `완료`). 검색창, 종류 칩 `전체 / 상의 / 하의 / 아우터 / 신발 / 기타`(가로 스크롤), `필터` 버튼(종류·계절·색상·보관 위치)과 정렬 `최근 등록순 ⌄`(또는 `이름순`)
- 본문: 2열 카드 그리드(태블릿 3열, 데스크톱 4~5열)
- 선택 모드: 체크 원, 하단 액션 바 `2개 선택됨 · 선택 해제 · [위치 변경]` → 장소 선택 시트(**목업 없음**) → 토스트 `n개의 옷을 '{장소}'로 옮겼어요`
- 빈 상태: `아직 등록한 옷이 없어요.` / `첫 옷을 등록해 보세요.` + [옷 등록]
- 검색 결과 없음: `'{검색어}'에 맞는 옷이 없어요.` + `필터 초기화`

## 3. 의류 상세 `/closet/[id]`

- 목업: `design/mockups/screens/0{2,4,6,8}_{season}_detail.png`, HTML `design/html/detail_{season}.html`
- 상단바: 뒤로, `옷 정보`, ⋯
- 본문:
  - 큰 사진 카드
  - 이름(22px)과 계절 배지(여러 개)
  - 위치 카드 `보관 위치` / `옷장 A › 왼쪽 행거`
  - 정보 표: 종류, 색상, 브랜드, 사이즈, 소재, 메모. 빈 값은 `미입력`
- `세탁·관리 정보`: 정보가 없으면 점선 박스 `등록된 관리 정보가 없어요.` / `세탁 라벨을 촬영해 추가할 수 있어요.` + [라벨 촬영](확장 기능)
- 하단 고정: `[위치 변경]`(주요) `[수정]` `삭제`(글자 버튼). 삭제 확인: `정말 삭제할까요? 코디에서도 빠져요.`

## 4. 옷 등록·수정 `/closet/new`, `/closet/[id]/edit`

- 목업: `design/mockups/screens/add_autumn.png`, HTML `design/html/add_autumn.html`
- 상단바: 뒤로, `옷 등록`(수정 시 `옷 정보 수정`)
- 사진: 104px 미리보기와 `사진을 올렸어요` / `옷 전체가 보이는 사진이 좋아요` + [다시 선택]. 올리기 전 상태는 `사진 올리기`(**목업 없음**)
- 필드:
  - 이름(입력)
  - 종류(칩 1개 선택: 상의·하의·아우터·신발·기타)
  - 색상(색 점 8개 + 오른쪽에 선택한 색 이름)
  - 계절(칩 여러 개 선택, 보조 `여러 개 선택할 수 있어요`)
  - 보관 위치(드롭다운, 보조 `모르면 '미지정'`)
- `자세한 정보 추가`를 펼치면 브랜드, 사이즈, 소재, 메모(모두 선택)
- 하단 고정: `[취소]` `[저장]`. 저장하면 내 옷장으로 가서 새 카드를 강조하고 `등록했어요` 토스트
- 검증: 이름이 비면 칸 아래 13px로 `이름을 입력해 주세요.`를 보여 준다. 오류 색은 아직 정하지 않았으니 임시로 `--deep`을 쓰고 팀 확인을 받는다.
- 사진 실패: `사진을 올리지 못했어요.` / `다시 시도해 주세요.` + `다시 시도` · `사진 없이 등록`

## 5. 보관함 `/storage`

- 목업: `design/mockups/screens/storage_autumn.png`, HTML `design/html/storage_autumn.html`
- 상단: `보관함`, 오른쪽 `[+ 장소 추가]`(작은 primary 버튼)
- 요약 카드(`--soft`): `옷 42벌 중 37벌의 위치가 정해져 있어요` + 진행 막대 + `88%`
- 장소 행: 겹친 썸네일 2~3개, 이름(16px/600), 보조 `행거 2 · 서랍 3 · 18벌`, ›
- 마지막 행은 점선의 `위치 미지정` / `5벌 · 위치를 정해 주세요` + 배지 `정하기`
- 장소 상세 `/storage/[id]`(**목업 없음**): 그 장소의 옷 그리드, `이름 수정`, `옷 이동`
- 장소 삭제 확인: `이 장소의 옷 n개는 '미지정'으로 바뀌어요.`

## 6. 코디 `/outfits`

- 목업: `design/mockups/screens/outfit_autumn.png`, HTML `design/html/outfit_autumn.html`
- 세그먼트: `만들기 / 저장한 코디`
- 만들기:
  - 고정 슬롯 2×2 캔버스(아우터·하의·상의·신발, 각 칸 라벨과 × 제거 버튼)
  - `내 옷장에서 고르기` + 종류 칩 + 가로 옷 목록(선택하면 체크와 primary 테두리)
  - 코디 이름 입력, `메모 (선택)` 입력
  - 하단 `[코디 저장]` → `저장한 코디` 탭과 `코디를 저장했어요` 토스트
- 저장한 코디 목록·상세(**목업 없음**): 카드에 구성 옷 썸네일. 상세에서 옷을 누르면 의류 상세로 간다.
- 옷이 부족할 때: `코디를 만들려면 옷이 2벌 이상 필요해요.` + [내 옷장으로]

## 7. 마이 `/my`

- 목업: `design/mockups/screens/my_autumn.png`, HTML `design/html/my_autumn.html`
- 프로필 카드(아바타, 이름, `내 계정`, [프로필 수정])
- 통계 3칸: 내 옷 · 코디 · 보관 장소
- 메뉴:
  - `화면 테마`(값 `● 자동 · 가을`)
  - `저장한 코디`(8개)
  - `보관 장소 관리`(6곳)
  - `알림 설정`
  - `도움말·문의`
- 별도 카드: `로그아웃`

## 8. 화면 테마 `/my/theme`

- 목업: `design/mockups/screens/theme_autumn.png`, HTML `design/html/theme_autumn.html`
- 안내: `'자동'은 한국 기준 계절에 맞춰 색이 바뀌어요.` / `화면 색상만 바뀌고 옷 정보는 바뀌지 않아요.`
- 라디오 목록:
  - 자동(`지금은 가을이에요`)
  - 봄 3~5월
  - 여름 6~8월
  - 가을 9~11월
  - 겨울 12~2월
  - 각 줄 오른쪽에 색 점
- 미리보기 카드(칩·버튼·배지), 하단 `선택하면 바로 적용돼요`. 저장 버튼은 없고 즉시 적용한다. 설정값은 사용자 설정으로 저장한다.

## 9. 목업이 없는 화면 (같은 시스템으로 설계해 구현)

- 장소 선택 바텀시트(위치 변경, 일괄 변경 공용)
- 장소 상세, 장소 추가·이름 수정 시트
- 저장한 코디 목록·상세
- 로그인·회원가입(범위 결정 후)
- 데스크톱 레이아웃(상단 바, 다열 그리드)
- 토스트, 확인 다이얼로그, 로딩·오류 상태
